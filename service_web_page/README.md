# SERVICE WEB PAGE

- The service web page is an elegant yet slightly playful website for a sales company.
- The website's Goals include

1. A list of services the company offers
2. About us section
3. Testimonials section

- The website is built using HTML, CSS and JS.

## SECTION LAYOUTS

1. HERO SECTION
- This section includes a catchy headline with an image or illustration.

2. SERVICE SECTION
- This section includes cards or grids for each service.

3. ABOUT US SECTION
- This section includes some key points and features

4. TESTIMONIALS SECTION
- This section includes rounded imges of peoples profiles and testimonials

5. FOOTER SECTION
- This section includes quickllinks to contact info, social links etc


## DESIGN ELEMENTS

1. COLOR SCHEME
2. TYPOGRAPHY
3. SPACING AND LAYOUT
4. ROUNDED CORNERS
